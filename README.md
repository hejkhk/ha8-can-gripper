# HA8-U35H-M 官方 USB 串口直连测试上位机（V3.2-beta）

本项目现以 **官方舵机扩展板 / 官方 USB 串口转接板直连** 为主，不再依赖 STM32F103、USB-CAN、CTS100M 或 CAN 标识符。

```text
Windows 电脑 ─USB→ 官方舵机转接板 ─→ HA8-U35H-M
                                           ↑
                                 按型号要求单独供电（如 12V）
```

- COM 端口：由 Windows 设备管理器确认，历史上直连曾使用 COM6，但不固定。
- HA8：115200、8 数据位、无校验、1 停止位（8N1）。
- 发送：`12 4C CMD LEN CONTENT CHECKSUM`。
- 接收：`05 1C CMD LEN CONTENT CHECKSUM`。
- Ping ID 0：`12 4C 01 01 00 60` → `05 1C 01 01 00 23`。
- 长指令通过 UART **一次连续发送完整请求**，不按 CAN 的 8 字节拆帧。
- `ha8_protocol.py` 独立维护控制指令和回包解析，`ha8_serial.py` 只处理串口通信。
- 新增 **夹持检测（实验性）** 页面：电流→动态扭矩参考、接触候选、稳定候选、堵转/过流报警、有效夹持角度区间、CSV 日志。
- 保留既有八个测试模块：位置控制、数据监控、停止与标定、通讯检测、参数读写、同步/异步、HA8 原始协议、串口调试。
- 高级同步/异步仍有固件版本限制；仅凭发出请求不能认为执行成功。
- 曾经使用的 CAN/F103 文件暂留作为历史兼容参考，**V3 主程序不再导入、也不再调用**。

## 运行

```powershell
pip install -r requirements.txt
python HA8_UpperComputer.py
```

先关闭官方串口调试软件，避免占用同一 COM 端口。正确连接扩展板与舵机并上电后，执行 Ping → 读取角度 → 数据监控 → 空载小角度运动。

详见 [doc/direct_usb_serial_mode.md](doc/direct_usb_serial_mode.md)。保留的 CAN 文档只是历史集成资料，并非 V3 的当前接线要求。

## 电流→动态扭矩与疑似夹持判定（V3.1-beta）

- `grip_estimator.py`：纯算法；曲线点可编辑，仅用于**动态参考扭矩**，静止/超范围输出“不适用”。
- `grip_panel.py`：检测界面（不会自动发送任何运动或停止命令）。
- 在“数据监控”页启动自动采样，建议周期约 100ms；采纳确认的空载电流基线；确认闭合方向和有效夹持角度区间；在“夹持检测”页启动一次判定，再到原位置页发送闭合运动。
- 异常状态锁存直到人工重置；未填写有效夹持角度区间时**不会输出夹持稳定候选**。
- **仅显示“疑似夹持稳定（未校验）”，绝不作为可靠抓稳或允许自动抬升的依据**。蜗杆自锁/静摩擦会导致静态电流与夹持力关系不可靠。
- 监控 CSV 末尾新增动态参考扭矩、角速度、判定状态与原因四列。
- [完整算法、模型局限及测试步骤](doc/grip_current_torque.md)；本模块的离线测试：`python -m unittest discover -s tests -v`。
- 先执行 `python -m py_compile HA8_UpperComputer.py ha8_protocol.py ha8_serial.py grip_estimator.py grip_panel.py` 检查语法，再运行测试与上位机。
- 新增断流锁存、首次采样超时、瞬时过流检测，均需要手动重新开始新的检测会话。

## 验证范围
过去已通过官方转接板 + USB-TTL 直接串口 Ping 验证；本次 V3 直连代码尚未在用户当前设备上验收。请依次测试运动、原点设置和高级指令。

## 自动抓取测试页（V3.2-beta）

已在主窗口提供“自动抓取测试”标签页。开发分支 `fix/v3-2-auto-grip-session-safety-20261018` 正在补完实验台架流程：**抓取、张开、一键软件急停、急停解锁、实时电流/角度、参数编辑和页内实时监控开关**。主分支在 PR 合并前仍为原 V3.2 实现。

- **要求抓取为角度减小、张开为角度增加**；先用人工位置控制确认零位、方向与真实硬限位，角度限制默认为空，未填写禁止动作。
- 从主窗口选择“自动抓取测试”：连接 COM 后点击**开启实时监控**（共享数据监控页已有的轮询任务，不额外占用串口），确认电流和角度实时变化；建议在数据监控页设周期 100ms。然后填写已标定的抓取最小角度和张开最大角度、合适的低速及功率，最后再按**抓取**或**张开**并确认。未确认真实方向、机械限位或没有独立硬件断电急停时不要执行运动。
- 每次动作前要求已连接官方串口、监控反馈新鲜且状态字无故障；正在运行时禁止修改参数。参数在一次运动开始时冻结，主位置页不可覆盖自动运动；除只读监控与对应舵机的保持 STOP 外禁止其他页面发送指令，包括原始串口命令。
- 抓取发向最小角度的多圈角度运动指令；基于现有 `GripDetector` 的接触/稳定候选、最小角度、保护位与通讯超时发送**保持停止命令**；张开达到设定最大角度附近同样尝试停止。
- **软件急停**使用 HA8 保持停止 0x18/0x11 并锁存人工解锁，依赖 USB、供电、舵机固件，**不是硬件安全急停**；仍需配备独立硬件断电急停。普通停止后要求连续监控反馈角度稳定才释放自动操作界面；断线、超时及停止无法确认均进入故障锁定。这个观察结果**不构成物理安全停止证明**，不能替代人工及硬件检查。
- 本功能尚未通过真实夹爪的动力学与限位测试，不能据此认定 3kg 夹持安全，也不能用来替代夹持力传感器。
