## 当前实现约束

- UART 原样写入完整 `12 4C CMD LEN CONTENT CHECKSUM` 指令，不需要 8 字节 CAN 分片。
- UART 接收是**字节流**，需按 `05 1C` 帧头、LEN 和 checksum 组帧。
- 程序使用官方转接板处理 HA8 本体的单线半双工通讯；不要直接将舵机 SIGNAL 误接独立 UART TX/RX。
- 已完成离线代码及协议检查不等于已完成真实舵机动作测试。
- 同步/异步需要确认当前 HA8 固件支持。电流—扭矩仅能作为估算参考，不能仅凭电流认为抓取可靠。
- 旧 `doc/CAN_protocol_robot_arm.md` 与 `doc/CTS100M_configuration.md` 是历史 CAN 集成记录，并非当前接线说明。
