## 使用边界

1. 图中曲线为厂家提供的性能特性图，不是直接来自本项目上位机电流采样的标定数据。
2. 未确认驱动内部的测量定义与图中的测试电流相同。不可直接把上位机回读电流乘以常数作为有保证的输出扭矩。
3. 在静止夹持时，蜗轮蜗杆静摩擦、自锁与不同爪角位置的力学传递使夹爪真实夹持力更复杂。
4. 建议先做电流上升 + 角速度下降 + 角度区间 + 故障状态的**疑似接触检测**。可靠抓稳仍需防滑裕度/实际负载验证。

> 后续如获得厂家针对 **HA8-U35H-M 12V 型号**的“静态保持扭矩—上位机回读电流”测试报告，再更新此文档及标定表。
