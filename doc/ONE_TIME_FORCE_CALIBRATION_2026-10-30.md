# HA8 夹爪单次 FSR 标定 → 无传感器离线估算（V3.6 实验交接）

> 2026-10-30 · 代码审核基线：HA8 main V3.5-beta + 本分支 V3.6  
> 唯一电脑上位机：仓库根目录 `HA8_UpperComputer.py`  
> 项目定位：**单指尖 FSR 理论受力的有限工况经验估算**，不是高精度双指总夹持力测量仪、闭环力控制或安全停止装置。

## 1. 实际目标

标定时一枚 IMS003-C10A-1KG 薄膜压力片放在某一只手指指尖，通过 STM32F103 ADC/USB-TTL 将 AO 转换板压力信号传给电脑；同时读取 HA8-U35H-M 舵机角度、电流和状态。上位机按 PC 时间将两路数据配对，保留 `(I_A, servo_angle_deg, phase, pressure_delta_ADC, theoretical_FSR_gf)`。

用一次包含若干安全夹紧/放松动作的会话建立并**保存本地数据模型**。以后可断开/移除 FSR 和 F103，在**相同夹具、同一夹持几何、标定覆盖的角度与电流、闭合运动期间**，查表/局部近邻推算当时 FSR 所代表的**单指尖局部法向力**，标注“未验证估算”，**绝不用于自动停止**。

不同物体材质、大小、接触点、夹口宽度、材料刚度、温度及传动摩擦都会改变关系。蜗杆自锁静止时的电机电流与指尖保持力不唯一，**没有压力传感器时无法保证真实夹力，不能用一次曲线推算所有工况**。

## 2. 三份用户文档的事实与量纲

### HA8-U35H-M Wiki（上传 PDF）

- 3.1 基础参数：电源 9.0～12.6V、**内部减速比 378:1**，UART 半双工；3.2 节 12V 参数：**额定 0.54 N·m、最大动态 1.27 N·m、静态堵转 3.43 N·m**；厂家 T-N/电流曲线是参考动态特性。
- 这些数值是 HA8 **输出轴参考力矩**，因此在外部蜗杆计算时**不能再乘378**。堵转数值不能当持续额定力矩。
- 仓库 `grip_estimator.py` 的 `REFERENCE_DYNAMIC_POINTS` 是人工目测厂商图表提取的粗略动态参考，仅运动时可给动态输出轴扭矩插值，**不代表静止时真实指尖夹力**。

### 机械外部传动（用户提供）

- 蜗轮：**模数 m=1，齿数 z₂=20**；蜗杆：**模数 m=1**。
- 外部传动比 `i_w = z₂ / z₁ = 20 / z₁`，其中 z₁ 为**蜗杆头数**。模数 1 **不能证明是单头蜗杆**，所以 20:1 尚未经确认。蜗轮理论分度圆直径 `m*z₂≈20 mm`，**不是**两指间距。
- 仅作理论结构分析：`T_wheel = T_HA8_output * (20/z₁) * η_w`，`F_tip≈T_wheel/r_eff(angle, contact)`。效率 η_w、接触法线方向、有效指尖力臂、连杆几何和摩擦未实测，**不能将此公式直接输出为实际牛顿值**。
- 舵机角度并不直接等于两指间距。程序另提供两组**实测舵机角度/夹口毫米距离**作为区间内的局部线性映射；若无两组记录，只显示角度，不伪造距离毫米。

### FSR 规格与转换板

- IMS003-C10A-1KG 规格书：标称量程 **1000gf**、最小测力约50gf、重复性约5%、迟滞约10%、高载蠕变明显。第2页出现2kg的实验电导点，不等于其已获2kg额定精度/寿命保证。
- AO转换板用户手册第5页给出 `Uo=0.1*(1+Rf/Rx)`。当前按 **Rf=158kΩ** 进行理论计算，尚无独立实测确认。零点只能消除偏置，不能修正个体传感器和增益误差。
- 一枚 FSR 仅测其贴附指尖受力区域的局部法向作用，**不是两指总夹紧力**；另一指、物体滑动/摩擦、真实接触面积均未测得。

## 4. 一次安全会话采集（必须有人看护）

1. 在无人靠近夹爪危险区域、已配独立硬件断电急停且**已验证硬限位和低速运动方向**的工装台，固定 FSR 与正对压力片的平整压头。**不要以“不断夹紧直到力够大”为唯一停止条件**；传感器标称仅 1kg。
2. 启动 `python HA8_UpperComputer.py`；按协议识别/选择独立 HA8 COM 与 STM32F103 COM。两路 115200/8N1 但数据协议完全不同。
3. 进入「压力验证 / 曲线」，无载稳定后采零点。在同页点“开始采集”，回「夹爪控制」执行低速、低功率、有限角度夹紧。可以在**一次标定会话**内分几次加载/卸载、停顿冷却，再继续采集；不允许机构或传感器超载。
4. “结束采集”后审核图表及 CSV，再点击**“从本次数据生成并保存模型”**。仅纳入 `phase=gripping` 且 `HA8 status=0`、压力模型处于 50～1000gf、配对时差0～180ms 的点。要求至少18点且跨度至少0.04A、0.5°和80gf，否则**拒绝模型**。
5. 可选填写两组**实际量出的**“舵机角度A/开口A(mm)”和“角度B/开口B(mm)”；两点间距仅按局部线性插值。不填就不输出毫米值。
6. 模型保存在**本机**的 `calibration/grip_force_model.json`，重启 GUI 自动加载。**接着可移除 FSR，仅接 HA8 COM**，但此时显示“估计”而不是“实时测力”。
7. 后续同工况低速闭合时，若实时 `current, angle` 同时处于训练区间且邻近有足够点，显示单指尖“≈gf（未独立验证）”；**静止、张开、状态异常、超出区间都不预测**。所有预测**只展示，不控制舵机、不触发 STOP**。

## 5. 当前训练算法的边界

- `ForceMap.train` 使用配对的 FSR **理论**克力作为目标，与电流+舵机角度二元特征组成局部训练集，当前保存原始点、实时计算7近邻加权平均；附近不足3个可靠点时返回 `None`。
- 这是一个**受限经验映射**，不是物理力矩反解、不是静态保持模型。训练期间的压片迟滞/安装与传动效率不确定性仍写入模型。它的“训练通过”不等于可跨物体泛化。
- 在新物体/不同摩擦/不同夹口/静止自锁时，电流与角度不能唯一决定夹紧力。失去直接力反馈后，不具备可靠的真实夹力闭环；想要安全限力必须保留可测力传感器或再加入经验证的闭环反馈。
- 现阶段**没有真实训练数据文件**，模型文件只在实际实验后生成；程序不捏造“预训练参数”或“已实测精度”。
- 采样配对按 PC 接收时刻，HA8约100ms一次，F103约10ms一次，非两MCU同步采样，时间错位最多允许180ms，快速瞬态不可当成同一时刻测量。
- **不能据此推断可安全搬起几公斤物体**：指端法向力不等于可抗滑移摩擦力，需另测摩擦系数、法向分布与动态加速度。

## 6. 构建、回归、后续

```powershell
py -3 -m pip install -r requirements.txt
py -3 HA8_UpperComputer.py
py -3 -m unittest discover -s tests -v
py -3 -m unittest discover -s extensions/gripper-pressure-f103/tests -v
```

后续工程优先级：
1. 确认蜗杆头数、机构连杆与指端有效力臂，标定实际夹口位置—角度曲线，不用外部蜗杆比直接冒充间距。
2. 断电复核 AO-RES 实际阻值、测 VDDA；利用可追溯已知法向力独立验证 FSR 与训练模型误差。
3. **至少保留传感器做一轮“训练后独立验证”**，避免训练集本身自证准确。分物体/夹口/加载卸载作对比；无此验证目前为实验级。
4. 如需静态夹紧力检测、自动防夹或确定允许提物条件，应引入可用的实时反馈与独立硬件安全措施。旧 HA8 动态 T-N 曲线和外部蜗杆乘比无法替代这部分测量。
