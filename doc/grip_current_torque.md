# HA8-U35H-M 电流—动态参考扭矩与夹持检测（V3.1-beta）

## 1. 目的与边界

此功能是**夹爪实验性检测器**，不是扭矩传感器、力控闭环或独立安全系统。舵机通过 HA8 官方 USB 转接板串口 `115200 8N1` 上报电流、角度与状态字。本软件对回包做解析，在本机推断接触与稳定性，不下发自动夹紧/抬升指令。

- **动态参考扭矩**：按厂商 12V 版 T-N 特性图的蓝色电流曲线做**粗略目测点**、线性插值。不是厂商逐点提供的数据，也不是静止夹持标定。
- **输入电流**：监控回包 `current_ma / 1000`，尚未证实与厂商测试曲线电流定义完全相同。
- 仅在电机实际运动且电流处于参考点范围内显示参考扭矩；**静止/保持、超出曲线范围返回“不适用”**，不外推至 3A 峰值，更不能转换为指端夹持力。
- **蜗轮蜗杆可能自锁**：静态夹持力与电流并非可靠的一一对应关系。电流高且位置停止也可能是机械限位/卡死。无测力/防滑实验时，最高只能显示“疑似夹持稳定（未校验）”，不能据此自动抬升。

## 3. 夹持候选判据

操作员选择闭合方向，并配置有效夹持角度区间（避开机械硬限位）；**手动开始本次检测**后，执行原有位置控制让夹爪闭合。采样周期建议约 100ms：

1. HA8 电流上升至高于预设空载基线 `I_baseline + ΔI`。
2. 当前闭合方向已累计移动至少设定角度，角速度下降到阈值以内。
3. 电流继续保持在最低“夹持候选电流”以上，持续超过稳定时间。
4. 当前角度处在用户确认的物体夹取范围内；超出区间可能是顶到机械限位。
5. 监控无超时，状态字没有堵转/过压/欠压/电流/功率/过温报警（bit2~7），电流未超过配置的异常阈值。

只满足 1–2 显示“疑似接触”；满足全部条件显示“疑似夹持稳定（未校验）”。**未设置有效角度区间**时不输出夹持候选结论。程序不会自动发送 Stop，也不会控制机械臂抬升或释放。

### 示例初始参数（仅用于空载摸底）

| 参数 | 默认值 | 用途 |
|---|---:|---|
| 空载基线 | 0.20 A | 空载电流的参考，应实测并修改 |
| 接触电流增量 | 0.18 A | 与基线之差达到该值 |
| 夹持候选电流下限 | 0.55 A | 仅为初始参考，**不是夹稳认证值** |
| 异常电流上限 | 1.50 A | 纯软件报警阈值，不代替硬件过流保护 |
| 低速阈值 | 2°/s | 角速度低于该值 |
| 稳定时间 | 0.50 s | 保持稳定的时间 |
| 最低闭合行程 | 2° | 排除起步后静止 |
| 反馈超时 | 1.50 s | 防止旧值冒充当前状态 |
| 有效夹持角度区间 | **空** | 必须针对机构自行填写才可出现稳定候选 |

## 4. 建议实际操作

1. 先 Ping，开启自动状态监控，确认回读电流/角度方向正确。
2. 不放物体，在正常空载闭合过程中记录电流作为基线（也可点击采纳当前电流；务必保证采纳瞬间无夹物和机械限位）。
3. 查明闭合过程中角度是增加还是减少，并确认夹物时的有效角度上下限。首次测试应远离硬限位，手持急停开关。
4. 设置参数，按“应用参数”，再点“开始一次夹持检测”；通过原有位置控制发出小幅闭合指令。
5. 查看实时电流、角速度、动态参考扭矩、判定状态；日志和 CSV 可供复盘。
6. 遇到“异常／疑似卡死”应立即根据实际机构采取安全停机措施。软件**不会擅自发送运动/断电/释放指令**。

## 5. 工程改进

获得拉压力计、应变片或合适力传感器后应直接测量指端接触力，在不同开口角度建立 `(电流,角度,载荷)→夹持力` 标定表，并进行实际负载摩擦/滑移测试。验证之前不应将候选状态作为机器人允许抬升的安全条件。

## 6. 断流、超时和候选撤销（防误判）

- 手动启动一次检测时即开始计算监控超时；即使没有收到第一帧反馈，也会进入“监控反馈超时”。
- 运行期间超过 1.5 秒没有新的有效反馈（可在纯算法配置里修改）后，判定锁存为超时；恢复串口并不自动重新宣告夹稳，需人工重启检测。
- 状态字的堵转/保护位或单次原始电流超过软件限值时，判定为异常并锁存；**这只是报警，程序不会替代硬件急停**。
- 电流回落到接触阈值以下，原先的“疑似接触”会被撤销；异常原始采样同样要求重新启动，避免跳帧冒充连续稳定。
- 监控 CSV 新增 `dynamic_torque_ref_Nm`、`angle_speed_dps`、`grip_state`、`grip_note`，保留原始电流和角度值，便于以后复盘和重新标定。

此功能与闭合电机指令完全分离，检测页的开始/停止只控制**判定器**，不控制电机。当前高电流、低速度以及持续时间阈值只是研发测试参考，不能当作可安全抓取 3 kg 物体的依据。
