# HA8 智能夹爪 + STM32F103 薄膜压力融合交接（2026-10-30）

> 软件版本：V3.4-beta；直接提交到 `main`。本文说明的是代码已实现的实验功能，不是已完成的实体夹爪安全/测力验收。
>
> **项目意图**：用户不希望把 FSR 压力数值作为直接运动控制输入，而希望**让压力片作为独立观察通道，验证 HA8 电流算法是否实际发生接触，并实验取得电流—压力响应曲线**。

## 1. 两路串口永远独立

```text
Windows 夹爪上位机 (HA8_UpperComputer.py)
  COM A: 官方 USB 串口板 ──> HA8-U35H-M 舵机 ──> 蜗轮蜗杆两指夹爪
  COM B: F103 USB-TTL   <── STM32F103(PA9 USART1)
                                ↑ PA1 ADC
                       AO 转换模块 <── IMS003-C10A-1KG
```

- HA8 使用原生 UART/115200 8N1；其运动、停止、夹持电流状态机仍由原 `auto_grip_panel.py`、`grip_estimator.py` 决定。
- 压力模块使用 F103 固件已有 `P,seq,mcu_ms,adc,mv,flags\r\n`（115200 8N1，典型约 100Hz），**不发送任何控制命令，也不需要重新烧录 F103**。
- 主程序使用 `pressure_validation.PressureSerialLink` 创建独立只读串口，线程只解析帧并投递到 Tk 主线程 `ui_queue`。不得与 HA8 控制串口共用。
- 主程序的“压力验证 / 曲线”页提供连接、零点、接触证据、实验曲线和 CSV；“夹爪控制”页保持简洁，仅多显示实验结论。
- F103 协议和厂家受力查表的**唯一维护源**仍是 `extensions/gripper-pressure-f103/PC_UpperComputer/protocol.py`。整合端通过文件路径加载它，不重新抄录厂家表。

## 2. 测什么、不能测什么

| 实验量 | 来源/定义 | 结论级别 |
|---|---|---|
| HA8 电流 A | 舵机 `CMD 0x16` 的 `current_ma/1000` | 实际报告电流，非单独可用夹力 |
| HA8 角度 °、状态、相位 | 舵机监控和自动抓取状态机 | 运动过程/异常标记 |
| 压力原始 ADC、mV | F103 `P` 串口帧 | 相对变化与趋势 |
| ΔADC | 当前 ADC − 无载采样中位数 | **接触压力变化证据**，无绝对力单位 |
| 理论受力 gf | 假定 AO反馈电阻 158kΩ + 零点 + 原厂电导—受力表 | **未经实测标定的理论估计** |
| 电流—压力曲线 | 主机时间配对的 HA8 电流与 ΔADC 或理论 gf | 实验参考关系，**不是已验证的真实夹紧力传递函数** |

158kΩ 是此前的软件设置，尚无独立实测电阻佐证；AO 公式 `Uo=0.1*(1+Rf/Rx)`，`G=(Uo-Uzero)/(0.1*Rf)`。零点只修偏置，不修正 FSR 个体差、接触几何、迟滞、蠕变及 VDDA 误差。规格书标称量程约 50–1000gf；超过 1kg 或小于约 50g 的量化读数不能据此保证精度。

**一片压在单指上的 FSR，即使检测到长时间受压，也不能验证另一指、是否顶到空行程硬限位、能否提起物体，尤其不能证明没有滑移。** 上位机用词严格为“接触证据”“持续受压证据”“数据不足/故障”，不显示“已抓稳/允许抬升”。

## 3. 零点与证据规则（软件初始值，待实测再调）

1. 在压力片完全无载时采 1秒以上：至少 30 个有效样本，覆盖至少 0.7秒；拒绝过大波动，使用中位数作为 `zero_adc`，MAD×1.4826 估算噪声。
2. 只有 `flags==0`、`adc<4085` 的读数才能参与计算，遇到异常立即废止旧读数的“实时有效”资格。有效数据超过 0.3秒即标为过期。
3. 接触证据：最新 0.6秒中的至少 8 个有效样本，`median(ADC)-zero_adc >= max(20,6*noise_ADC)`。这些是初始保守**实验阈值**，不是传感器出厂阈值，也不构成真正夹紧判定。
4. 持续受压证据：最新约 0.9秒中有效数据至少 20 个、覆盖至少 0.7秒，≥85% 超过上述阈值。即使成立也不证明不打滑。
5. 监控失联、ADC 故障、饱和、无有效零点或停机未确认均不得给出积极的“夹稳”结论。

## 4. 推荐实验流程

1. 确认 HA8 供电和机械限位，配备**硬件独立断电急停**；将无载夹爪固定台架；先用安全小角度、低速试验确认闭合方向。
2. HA8“夹爪控制”选 COM A → 连接；“压力验证 / 曲线”选另一个 COM B → 连接。注意 Windows 以前可能将 F103 分配为 COM4，但不能写死。
3. 压力片处于实际安装位置且完全无载，稳定至少 1秒，点击“无负载采集零点”。
4. 在曲线页点击“开始采集”，切回夹爪控制页让夹爪以已校准的允许角度低速闭合；抓取电流算法**不读压力变量**、仍按之前的条件停止。
5. 停止后在主页面看“压力验证”结果；等待压力稳定后可在曲线页点“检查当前压力接触”，辨别短暂与持续压力；张开观察压力消失趋势。
6. 点击“结束采集”，选 ΔADC 或未标定理论 gf 作为纵轴查看散点与趋势线，导出 CSV。
7. 更换 2–3 种可复现的软质试样，进行多轮夹紧/卸载，记录同速度、相同夹持角度下差异。如果希望取得可推广的末端真实夹力曲线，后续仍须**独立已知法向力基准**进行检验，或使用标准测力仪。不能把物体质量当作夹爪法向夹紧力。

## 5. 数据配对、曲线、CSV 与边界

HA8 约每 100ms 返回一个监控包；F103 通常每 10ms 发一帧。上位机按双方**本机接收时刻**进行最近样本配对：压力帧必须在 HA8 当前监控包之前不超过 180ms；记录时间偏差 `skew_ms`。这是近似同步，不是两 MCU 同一时钟/同一时刻的物理测量。异常状态样本直接排除拟合，但保留各模块原始调试功能。每次实验自动采样最多 30000 个配对点以保护内存。

CSV 列名：
`pc_time_s,trial,servo_id,current_A,angle_deg,phase,ha8_status,pressure_ADC,pressure_delta_ADC,pressure_mV,theoretical_gf_unverified,pressure_seq,skew_ms`

图形：
- 横轴 `HA8 电流(A)`；纵轴可切换 `ΔADC` 或 **理论 gf**。
- 蓝色散点是主机配对数据；有足够分布时橙线为各电流分区的中位数趋势，不做超界外推或虚假高精度拟合。
- 实验曲线不会自动变成生产控制用的电流—夹力查表。不同目标物、夹口位置、静止保持和运动过程中电机电流的含义都可能不同。

## 6. 实现文件与测试

- `pressure_validation.py`：单独串口、复用 F103 原始协议/158kΩ 理论计算、零点、压力接触证据、两个 COM 的数据配对及 CSV。
- `pressure_lab_panel.py`：压力连接、只读状态、绘图、采集、CSV 导出。
- `HA8_UpperComputer.py`：新增压力实验页，主队列分发 F103 反馈；将 HA8 `CMD 0x16` 数据复制一份给实验记录器。
- `auto_grip_panel.py`：抓取开始/停止结束时**通知**实验页面，只显示验证提示；未改变舵机运动/停止条件。
- `tests/test_pressure_integration.py`：帧、零点、故障、接触证据、配对时差、CSV、GUI 与控制隔离回归。
- `.github/workflows/python-tests.yml`：Linux/Xvfb 运行 HA8 全部 Tk/串口/算法测试，额外运行 `extensions/gripper-pressure-f103/tests` 原始协议测试。

**尚待 Windows 实机验收**：两个 COM 同时接入时的实际采集速率和抖动、USB 异常拔插、压力片安装后的空载波动、多个材料接触曲线重复性、HA8 抓取误停/延时以及 FSR 长时间蠕变和结构抗滑试验。CI 通过只是离线模拟通过，不能代替实机结果。
