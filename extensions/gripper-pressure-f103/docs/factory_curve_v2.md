# STM32F103 夹爪力监测上位机 v2：厂家曲线快速估算

## 当前项目阶段

已验证的现场现象：用户截图显示 COM4、115200、约 100 帧/秒，按压压力片时 ADC/电压正常增加，说明 STM32 固件与上位机采集链路已可用。**本版只更新 Windows 上位机，固件保持不变。**

## v2 新功能

- 新增两个选项卡：**厂家曲线 · 快速** / **多点实测 · 精确**。
- 厂家曲线模式内置 IMS003-C10A-1KG V1.0 规格书第 2 页的完整受力-电导表，使用分段线性插值，不用主观虚构传感器的 ADC-受力关系。
- 仅需 **0 g 无载零点 + 1 个真实已知受力点**，计算近似克力和牛顿，仍可显示 60s 曲线、峰值，CSV 增加 `calibration_mode` 列。
- 保存为 `PC_UpperComputer/calibration.json`（v2 格式）；自动兼容 v1 的完整多点标定文件。
- 左侧表单支持滚动，避免小分辨率窗口裁剪按钮。
- 有效性检查：无串口帧、ADC 错误或接近饱和、ADC/参考点差不足 20、载荷未稳定、厂家参考范围外，均不能当作有效受力测量。
- 修改了实测标定文件的保存：未完成的单点标定不写入为完整多点曲线。

### 推荐：仅更新上位机

解压 `Gripper_Pressure_PC_v2.zip`，将 `PC_UpperComputer/gripper_monitor.py`、`PC_UpperComputer/protocol.py`、`PC_UpperComputer/requirements.txt` 放到之前能运行的电脑端同一目录，**三个文件一起覆盖**。不要只替换 GUI 主程序而忽略 `protocol.py`，否则导入会报错。


## 厂家曲线估算操作（推荐先用这个模式）

1. 打开程序，选择 COM4（或实际端口），连接 115200，确认 ADC、电压随按压变化。
2. 让夹爪上安装的压力片**完全卸载**，且等待 1 秒以上。点击 `① 松开夹爪，采集无载零点`。这将更新零点并清空之前的参考点。
3. 使用砝码、测力计或加载工装，在**实际传感器受力位置和方向**施加已知法向力。例如 500 gf（约 4.903 N），不是夹爪夹住一个 500 g 物体的重量：物体重量并不等于夹紧力。
4. 稳定加载至少 1 秒，在参考受力栏填 `500`，点击 `② 稳定施加已知受力，采集参考点`。
5. 左侧读数将显示 `≈ xxx.x g` 和相应牛顿值；符号 `≈` 表示厂家参考估算，不是高精度实测认证值。点击 `保存当前标定/模式` 以保存到 `calibration.json`。下次启动自动加载。
6. 若需要提高准确性，切换至 `多点实测 · 精确`，按多个真实法向力点逐个采集。保存后下次会使用当前选择的模式。

厂家表格（电导单位 1/kΩ）：

| 法向受力(gf) | 电阻(kΩ) | 电导(1/kΩ) |
|---:|---:|---:|
| 0 | >2000 | 0.0000（近似） |
| 50 | 160 | 0.0063 |
| 100 | 90 | 0.0111 |
| 200 | 49 | 0.0204 |
| 500 | 18 | 0.0556 |
| 1000 | 9.8 | 0.1020 |
| 2000 | 5 | 0.2000 |

## 为什么厂家曲线仍需一次参考力？

规格书第 2 页横坐标是 *受力 F*、纵坐标是 *传感器电导 G = 1/R*；并没有你这块单独购买的“5V 线性电压转换模块”的真实内部增益、偏置。该模块还可通过 AO_RES 调增益，所以不能凭 ADC=1744 或 1.405V 就唯一确定力值。

本版估算模型是 **ADC ≈ A0 + K×G(F)**。已知无载 ADC=A0、已知参考载荷 F_ref 时的 ADC=A_ref，就可估计：

```text
G_est = (ADC - A0) / (A_ref - A0) * G(F_ref)
F_est = 在厂家表格中，对 G_est 查表并分段线性插值
```

这是**工程假设**：如果转换板的输出本身是“对 F 线性”、带有额外非线性、电位器设置改变、输出饱和、温漂等，厂家曲线估算仍会产生误差。实际精度必须使用独立已知法向力进行验证。偏离 0～2000g 参考区间时不作外推；未稳定或状态异常则不显示可信力值。

## 限制及安全注意

- 首页规格书标称量程 **1kg**，第 2 页虽给出 **2kg 参考电阻/电导值**，但这不是对 1～2kg 的精度和寿命保证。
- 厂家说明最小测力约 50g、重复性 5%、迟滞约 10%、高载蠕变明显；尤其小于 50g 的显示不可视为已保证的准确检测。
- 换传感器、夹爪压头、安装贴附方式、AO_RES 增益、采样电源后，零点/参考点需重采。夹爪预紧力会改变无载状态。
- 本项目只是监测受力，**不是安全停机装置，也不提供闭环保护**。
- 本版固件协议保持 `P,seq,mcu_ms,adc,mv,status`，100Hz，115200 8N1；不需要修改 STM32。
