# STM32F103C8T6 夹爪压力监测系统（v1）

## 1. 本次交付

这是直接从用户提供的 CubeMX/Keil `Gripper_Pressure_F103` 工程修改而成的 **源代码工程**，并包含一套 Windows Python/Tkinter 上位机。

- `Gripper_Pressure_F103.ioc`：把 ADC1_IN1 采样时间从 1.5 Cycles 改为 239.5 Cycles。
- `Core/Src/main.c`：ADC 上电校准、16 次读取平均、EMA 定点滤波、每 10ms 串口发送一帧。
- `PC_UpperComputer/gripper_monitor.py`：上位机 GUI（USB-TTL 串口连接、读数、60 秒曲线、实际载荷分段标定、峰值、CSV 保存）。
- `PC_UpperComputer/protocol.py`：协议解析、标定曲线计算。
- `PC_UpperComputer/requirements.txt`：Python 依赖。
- `tests/test_protocol.py`：协议/标定单元测试。

**注意：未接硬件实测；未在你电脑上的 Keil 环境中重新生成 HEX。** 已完成对 19 个 STM32 源文件/启动文件的 ARM 目标交叉编译检查（Clang），以及 PC 端 Python 测试；请在本地 Keil 中正式 Build、烧录并验证。

## 2. 硬件接线（上电前核对）

| 元件 A | 元件 B | 用途 |
|---|---|---|
| FSR 传感器 2 线 | 线性电压转换板的传感器端子 | 力敏电阻接入 |
| 转换板 VCC | 稳定 5V 电源 | 按卖家标称的 5V 供电 |
| 转换板 GND | STM32 GND | 共地 |
| 转换板 AO | F103 PA1 | ADC1_IN1 |
| F103 PA9 (USART1_TX) | USB-TTL RXD | 发送数据到电脑 |
| F103 PA10 (USART1_RX) | USB-TTL TXD | 为未来接收指令预留，目前固件不处理指令 |
| F103 GND | USB-TTL GND | 串口共地 |

- **必须确认转换板 AO 真正为 0–3.3V，任何时候不得超过 STM32 的模拟输入允许范围。** 板子宣传的输出 0–3.3V 未经实测验证。先用万用表在无载/有载情况下测量，再连接 PA1。
- USB-TTL **信号电平**必须为 3.3V TTL（与转接板供电电压不是一回事）；有些转换器 TXD 在 5V 供电时输出 5V，需要确认或电平转换。
- USB-TTL 的 VCC **无需连接** 到已经独立供电的 STM32 板子。不要把两路电源硬接在一起。
- STM32F103C8T6 的 PA1 是 ADC 输入，不是 5V 容忍模拟输入。
- 使用 ST-LINK SWD 烧录：PA13/SWDIO、PA14/SWCLK、GND；按开发板实际供电方式连接 ST-LINK 参考电压。
- 请以转换板 PCB 丝印为准确认 VCC/GND/AO/DO 的**真实引脚位置**，不要仅凭淘宝展示图推断排针顺序。DO 本版本不接。

## 3. STM32 工程编译及串口验证

1. 用 Keil MDK 打开 `MDK-ARM/Gripper_Pressure_F103.uvprojx`。
2. 检查使用 `STM32F103C8`，点击 **Rebuild**。成功后再连接 ST-LINK 下载。
3. BOOT0 拉低，按开发板要求复位。
4. 电脑插入 USB-TTL，使用串口调试助手打开相应 COM 端口，`115200, 8N1, 无流控`。
5. 正常每约 10ms 收到一行 ASCII：

```text
P,0,3,1250,1007,0
P,1,13,1264,1019,0
P,2,23,1280,1031,0
```

以上为**协议示例，不是真实传感器读数**。

字段格式：`P,seq,mcu_ms,adc,mv,status` + `\r\n`

| 字段 | 含义 |
|---|---|
| seq | 从 0 递增的帧序号，超限自动回绕 |
| mcu_ms | `HAL_GetTick()` 单片机上电毫秒数 |
| adc | 16 次平均后，EMA 滤波后的 12 位 ADC 数值（0–4095） |
| mv | adc × 3300 / 4095 得到的名义电压（mV） |
| status | 状态位，`0` 正常 |

状态位含义：bit0(`1`)=ADC 读取失败；bit1(`2`)=高电压端接近饱和；bit2(`4`)=ADC 上电校准失败。如果 ADC 错误，固件发送上次有效 ADC **同时置错误标志**，电脑不能当作新的测量值。

**重要**：3300mV 是 STM32 的名义 ADC 参考值，不代表板上真实 VDDA 精确等于 3.300V。如果要提高电压精度，实测 VDDA 并更改 `Core/Src/main.c` 中 `ADC_REFERENCE_MV`。

## 4. Windows 上位机使用

安装 Python 3.10 或更高版本，在 CMD/PowerShell 进入 `PC_UpperComputer` 文件夹：

```powershell
py -3 -m pip install -r requirements.txt
py -3 gripper_monitor.py
```

操作步骤：

1. 选择 USB-TTL 对应的 COM 口 → **连接 115200**。
2. 先观察 ADC（0–4095）及电压的变化。即使**没有标定**，电压曲线也会显示。
3. 在最终夹爪机械安装状态下，把夹爪放在无载的重复位置，输入 `0`g，待约 1s 稳定，点击 **采集标定点**。
4. 使用**已知力/载荷标定装置**依次施加 50、100、200、500、1000g 等载荷，每次待稳定后采集对应标定点。若需要测试 1500/2000g，务必事先确认传感器和夹爪结构可以安全承受。
5. 至少两点且 ADC 对载荷单调后，自动切换显示单位 `g`（**克力**，而非质量称重）；同时显示 N（1g力 = 0.00980665N）。
6. 点击 **保存标定**，生成 `PC_UpperComputer/calibration.json`。下次启动自动加载。**调整 AO_RES、改变受力结构、替换传感器后必须重新标定。**
7. 点击 **开始 CSV 记录**，指定文件名，实时保存原始 ADC、mV、标定 g 和 N。

- 标定采用相邻点间的**分段线性插值**，不使用厂家电阻曲线直接强行推导转换模块电压。
- 上位机会拒绝非单调标定点，并在超过已标定范围时显示未测量/超范围，而不是向外无限外推；在 0g 以下的一侧会钳位为 0。
- 清除峰值不会改变标定；如果需要软件零点校正，请重新采集 0g 标定点并保存。
- 采集标定时使用最近最多 100 帧的平均值，若 ADC 波动大，会提示重新稳定加载。

## 5. 测量定位及风险

- **本系统是夹爪接触力的估计工具，不是安全认证的夹持力传感器。** 不可只依靠本装置保护人员或贵重物品。
- 厂家 1 页标称量程为 1000g，2 页的参考表包含 2000g 电阻点；`2kg` 只是**文档给出数据点以及用户描述的厂家实际工作说明**，不能据此保证 1–2kg 精度、抗蠕变或寿命。
- 转换板具备调零/调增益电位器，但实际传递函数未知；理论的电阻—力图不能替代对整个**机械结构 + 传感器 + 转换板 + ADC**系统的标定。
- 测量重复性、迟滞、蠕变和压头接触面积、夹爪预紧力、位置、胶水安装方式都会影响读数。
- 滤波提升显示平滑性，但会引入动态延迟；如果之后做闭环抓取控制，需要评估与电机控制周期之间的关系。
- 当前 Windows GUI **仅进行监测/记录**，USART1 RX 虽启用但没有实现远程电机控制或硬件急停。

## 6. 若运行不正常

| 现象 | 排查方向 |
|---|---|
| COM 无数据 | PA9→USB-TTL RXD、两侧 GND、115200、程序已烧录、BOOT0 拉低 |
| GUI 显示未标定 | 正常。先录入 >=2 个实测砝码标定点 |
| ADC 始终 0 | 用万用表测 AO；模块 5V 电源、FSR 接口和增益设置 |
| ADC 接近 4095 或 flags=2 | 模块过大增益/输出过压，先拔掉 PA1 验证 AO 安全 |
| 数值抖动大 | 共地、传感器固定、连接线屏蔽、稳定压头与电源 |
| 标定非单调 | 载荷位置偏移、传感器打滑、模块增益或夹爪机构改变 |
| Keil 报编译器问题 | 原工程使用 MDK ARMCC5；如提示 Pack/编译器缺失，请在 Keil 中选择已安装的工具链与 STM32F1xx DFP |

```bash
python -m unittest discover -s tests -v
```
